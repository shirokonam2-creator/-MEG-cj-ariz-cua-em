# ArizuOS Backup Settings

Cài đặt sao lưu và khôi phục dữ liệu.

Các chức năng:
- Chọn dữ liệu cần sao lưu.
- Chọn vị trí lưu backup.
- Đặt tên bản backup.
- Tự động sao lưu.
- Quản lý số lượng bản backup.
- Xác nhận trước khi khôi phục.
- Không tự động xóa dữ liệu gốc.

Nguyên tắc:
- Backup không thay thế dữ liệu gốc.
- Không xóa dữ liệu người dùng khi backup.
- Không tự động khôi phục nếu chưa có xác nhận.
- Người dùng có quyền thay đổi các cài đặt.
