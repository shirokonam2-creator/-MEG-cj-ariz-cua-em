# ArizuOS Backup

Mục tiêu:
- Tạo bản sao lưu trước khi thay đổi hệ thống.
- Giúp người dùng khôi phục dữ liệu khi cần.
- Không tự động xóa dữ liệu gốc.

Các loại dữ liệu cần ưu tiên sao lưu:
- Ảnh
- Video
- Tài liệu
- Tệp cá nhân
- Cấu hình ArizuOS
- Dữ liệu ứng dụng nếu hệ thống cho phép sao lưu

Nguyên tắc:
1. Bản sao lưu không được thay thế dữ liệu gốc.
2. Không xóa dữ liệu gốc sau khi backup.
3. Người dùng phải biết nơi lưu bản backup.
4. Có thể tạo nhiều bản backup.
5. Trước thay đổi hệ thống lớn, ưu tiên tạo backup.
6. Khôi phục phải có xác nhận của người dùng.
