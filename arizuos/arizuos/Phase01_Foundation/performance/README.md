# ArizuOS Performance System

Hệ thống quản lý hiệu năng của ArizuOS.

## Mục tiêu

- Giúp ứng dụng hoạt động ổn định.
- Ưu tiên tài nguyên hợp lý cho game.
- Hạn chế tác vụ nền không cần thiết.
- Theo dõi tình trạng hệ thống.
- Theo dõi nhiệt độ thiết bị.
- Bảo vệ các ứng dụng quan trọng.
- Tự động trở về chế độ bình thường sau khi thoát game.

## Các chế độ

### Normal Mode
Chế độ sử dụng thông thường.

### Game Mode
Tối ưu tài nguyên cho game đang chạy.

### Protected App Mode
Giúp các ứng dụng quan trọng được hoạt động ổn định.
